# Spec: Buster Text Format Parser

## Description

A parser for text files generated by `MC_Buster` and `MM_Buster` (MasterCook / Meal-Master conversion utilities). These files typically have a `.mxp` or `.txt` extension but contain plain-text recipes separated by `══════` banners. 
The format is distinctive in how it wraps long ingredient lines into continuations.

## Input Samples

### Sample 1: `nux/Test/HTML/rec.mxp`
**Location:** `nux/Test/HTML/rec.mxp`

```text
══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

                                                    [3][Home]  Baked Indian Pudding (Ai)  [4][Home]  

══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════


Title: Baked Indian Pudding (Ai)
Yield: 1 Servings

Ingredients

      3 c  milk
      4 tb corn meal
      1 sm red chilli; deseeded and
           -finely
      1    ; chopped

Instructions

Scald milk. Mix together meal and molasses and stir into hot milk.
```

## Expected Behavior

### Field Mapping
- **Recipe Boundary**: Recipes start with `Title: ` and end when a new title is found or EOF. The ═ banners can be ignored.
- **Title**: Extracted from `Title: (.*)`
- **Yield**: Extracted from `Yield: (.*)`
- **Ingredients**: Section starts after `Ingredients` and ends at `Instructions`.
  - **Funky Continuation Rules**:
    1. If a line starts with optional whitespace followed by a hyphen `-`, it is a continuation of the previous ingredient line. The `-` is stripped.
    2. If a line starts with `1` followed by optional whitespace and a semicolon `;`, it is ALSO a continuation of the previous ingredient line. (e.g. `      1    ; chopped`).
- **Instructions**: Section starts after `Instructions` and continues until the end of the recipe block (or the next ═ banner / Title line).

### Edge Cases
1. Missing `Yield:` line
2. Continuation lines occurring sequentially (e.g., a `-` line followed by a `1 ;` line). They should all concatenate to the original base line.

## Detection Contract

| Condition | Expected Score | Rationale |
|:---|:---|:---|
| Content contains `Converted by MC_Buster.` or `Converted by MM_Buster` | `>= 0.99` | Definitive signature of the Buster utility |
| Content contains `Title: ` and `Ingredients` and `Instructions` in expected text structure without Buster signature | `>= 0.50` | Fallback text structure |

## Golden Output (Canonical JSON-LD)

```json
{
  "@context": "https://schema.org",
  "@type": "Recipe",
  "name": "Baked Indian Pudding (Ai)",
  "recipeYield": "1 Servings",
  "recipeIngredient": [
    "3 c milk",
    "4 tb corn meal",
    "1 sm red chilli; deseeded and finely chopped"
  ],
  "recipeInstructions": [
    {
      "@type": "HowToStep",
      "position": 1,
      "text": "Scald milk. Mix together meal and molasses and stir into hot milk."
    }
  ]
}
```
